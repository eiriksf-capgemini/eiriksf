# assets

Originalfiler som ikke serveres av siden, men som er verdt å ta vare på fordi
det ikke finnes en kopi andre steder.

- `bw-profil-esf.png` – kildebildet bak profilbruken på siden (640×640, s/h).
  Ikke referert fra `app/`, `components/` eller `content/`; ligger her som
  arkiv, ikke som en ressurs bygget bruker.

Mappen er ekskludert fra Docker-build-konteksten (se `.dockerignore`).
